# LCFU 雷达配置工具 (GUI 版本) - QWEN Context

## 项目概述

这是一个用 Racket 编写的图形界面工具，用于 LCFU（Low-cost FPGA Unit）雷达设备的配置读写操作。该工具提供了一个用户友好的图形界面，支持通过 UDP 协议与雷达设备进行通信，实现配置文件的写入和读取功能，并包含实时日志显示、进度条、数据验证等功能。

## 项目结构

```
lcfu_gui/
├── lcfu_protocol.rkt      # 协议公共模块（字节序转换、CRC32等）
├── lcfu_write_lib.rkt     # 写协议核心库
├── lcfu_read_lib.rkt      # 读协议核心库
├── lcfu_gui_main.rkt      # GUI 主程序
├── README                 # 项目说明文件
└── compiled/              # Racket 编译缓存文件
```

## 核心模块说明

### 1. lcfu_protocol.rkt
公共协议模块，提供：
- Big Endian / Little Endian 字节序转换函数
- CRC32 校验计算实现
- 校验和计算函数
- 统一的异常类型定义（超时、协议、IO、验证异常）
- 网络通信函数（UDP 发送/接收，带超时处理）
- 辅助函数（字节到十六进制字符串转换、文件大小格式化）

### 2. lcfu_write_lib.rkt
写协议库，实现：
- 6 步写入协议（握手→升级→擦除→数据→完成→校验）
- Big Endian 字节序的协议包构建与解析
- 带进度回调和日志回调的异步操作
- 自动重试机制和异常处理
- 数据传输进度跟踪

### 3. lcfu_read_lib.rkt
读协议库，实现：
- Little Endian 字节序的协议包构建与解析
- 分包读取协议和数据组装
- 数据验证功能（与原始数据对比）
- 带进度回调和日志回调的异步操作
- 自动重试机制和异常处理

### 4. lcfu_gui_main.rkt
GUI 主程序，提供：
- 连接设置界面（IP地址、写端口、读端口）
- 写入/读取双面板界面
- 配置文件选择和验证
- 实时日志显示（带时间戳和状态标识）
- 进度条显示
- 状态栏信息
- 文件浏览和保存功能
- 线程安全的操作执行

## 协议细节

### 写协议（Big Endian, UDP 8082）
- 协议头：0xAAAA5555
- 6 步流程：握手 → 升级 → 擦除 → 数据传输 → 完成确认 → 完整性校验
- 每个步骤都有对应的请求和响应命令
- 数据块传输带确认机制和重试逻辑

### 读协议（Little Endian, UDP 8083）
- 请求标志：0xA5A5A5A5
- 响应标志：0x5A5A5A5A
- 分包读取，自动组装完整文件
- 支持雷达类型识别和数据验证

## 功能特性

### 写入配置 (Write)
1. 选择配置文件（自动显示大小和 CRC32）
2. 配置块大小（默认 1024 bytes）
3. 点击 "开始写入配置" 执行 6 步协议：
   - 握手验证
   - 升级请求
   - Flash 擦除
   - 数据传输（带进度显示）
   - 传输完成确认
   - 完整性校验

### 读取配置 (Read)
1. 选择验证文件（可选，用于数据验证）
2. 指定保存文件名
3. 配置块大小（默认 1400 bytes）
4. 点击 "开始读取配置" 执行：
   - 分包读取数据
   - 自动组装完整文件
   - 数据验证（如果提供验证文件）
   - 保存到本地文件

### 连接设置
- 目标 IP 地址（默认：192.168.1.10）
- 写端口（默认：8082）
- 读端口（默认：8083）
- 超时时间（5 秒）
- 最大重试次数（3 次）

### 日志功能
- 实时显示操作过程
- 带时间戳的日志记录
- 带状态标识（✓ 成功、✗ 错误、⚠ 警告、== 步骤）
- 支持清空和保存到文件

## 错误处理

程序实现了完善的错误处理机制：
- 超时异常（exn:lcfu:timeout）
- 协议异常（exn:lcfu:protocol）
- IO 异常（exn:lcfu:io）
- 验证异常（exn:lcfu:verify）

所有错误都会在日志中显示，并通过弹窗提示用户。

## 设计特点

1. **模块化设计**：拆分为协议、写库、读库、GUI 四个模块
2. **回调机制**：支持日志回调和进度回调
3. **线程安全**：GUI 操作在主线程，协议操作在工作线程
4. **用户友好**：图形界面、实时日志、进度显示
5. **错误提示**：友好的错误消息和状态提示

## 依赖要求

- Racket 7.0 或更高版本
- racket/gui 库（Racket 自带）
- racket/udp 库（用于 UDP 通信）
- racket/bytes 库（用于字节操作）

## 开发约定

- 代码使用中文注释和变量名
- 所有协议相关函数都遵循特定的命名约定
- 日志消息使用预定义的类型（step, success, error, warning, info）
- 异常处理遵循统一的结构体定义

## 注意事项

1. 确保目标设备 IP 和端口配置正确
2. 写入操作会擦除设备 Flash，请谨慎操作
3. 读取验证功能可确保数据完整性
4. 操作过程中请勿关闭程序
5. 建议在操作前保存日志以便调试
